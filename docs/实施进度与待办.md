## 已知边界

- 当前多工作区通过**独立数据库文件**隔离；这不是蓝图最终的 scoped schema。迁移决策见 [ADR-0001](adr/0001-workspace-directory-isolation.md)。
- 规则和内容新动作已携带 `TargetRef.workspaceId`；其余旧控制面仍有活动工作区语义，需逐步迁入统一 ActionRegistry。
- TaskService 的 JSON journal 已跨重启恢复，尚无事件表、压缩和长期任务数量上限；损坏日志会隔离备份。
- 浏览器插件、登录状态、Cookie/站点存储的跨工作区数据库级台账，以及检查点恢复尚未实现，不能宣称完整隔离保证。
- 2 MiB 非流式响应已经越过旧 256 KiB 门槛进入 ContentStore；流式/SSE 和浏览器未交付的正文仍会留下缺口，不可宣称所有请求都有完整正文。
- 证据 JSONL 哈希链可检测局部篡改，但不具备对本机文件所有者的强不可抵赖性；显式清理尚无自动 TTL/配额执行器。见 [ADR-0002](adr/0002-content-evidence-and-retention.md)。
- T-005～T-009 共用实现提交 `94958b0`，只能批量回退；本轮验收须接受或修正此 SOP 例外。
