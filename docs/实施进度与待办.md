## 已知边界

- 多工作区继续用**独立数据库文件**隔离，同时 v9～v11 为元数据行增加 workspace/profile scope 与迁移备份；尚不是所有旧控制动作统一 scoped 的终态。见 [ADR-0001](adr/0001-workspace-directory-isolation.md)、[ADR-0004](adr/0004-scoped-metadata.md)。
- 规则和内容新动作已携带 `TargetRef.workspaceId`；其余旧控制面仍有活动工作区语义，需逐步迁入统一 ActionRegistry。
- TaskService 的 JSON journal 已跨重启恢复，JSONL 事件支持单调 cursor 与 8MiB 压缩；尚未迁入正式事件表，也没有长期任务数量上限，损坏主日志会隔离备份。
- 登录证据、扩展观察和独立工作区检查点已有台账；Cookie/站点存储的全部历史归属与完整插件安装管理仍未收口。插件缺席只能报 `unknown`，见 [ADR-0007](adr/0007-extension-observation.md)。
- 已支持上传、普通响应、WS、SSE、下载、cache/SW 正文；opaque、浏览器内部请求或内核未交付字节仍会留下显式缺口。代理尚不支持 WebSocket upgrade，WS 由 CDP 路径采集。
- 证据 JSONL 哈希链可检测局部篡改，但不具备对本机文件所有者的强不可抵赖性；显式清理尚无自动 TTL/配额执行器。见 [ADR-0002](adr/0002-content-evidence-and-retention.md)。
- T-005～T-009 共用实现提交 `94958b0`，只能批量回退；本轮已接受该历史 SOP 例外，后续任务仍须恢复独立可回退提交。
