## 已知边界

- 多工作区继续用**独立数据库文件**隔离，同时 v9～v11 为元数据行增加 workspace/profile scope 与迁移备份；尚不是所有旧控制动作统一 scoped 的终态。见 [ADR-0001](adr/0001-workspace-directory-isolation.md)、[ADR-0004](adr/0004-scoped-metadata.md)。
- 规则和内容新动作已携带 `TargetRef.workspaceId`；其余旧控制面仍有活动工作区语义，需逐步迁入统一 ActionRegistry。
- TaskService 的 JSON journal 已跨重启恢复，尚无事件表、压缩和长期任务数量上限；损坏日志会隔离备份。
- 登录证据和扩展期望/部分观察已有工作区级台账；但 Cookie/站点存储的全部历史归属、完整插件管理清单以及检查点恢复尚未实现，不能宣称完整隔离保证。插件缺席只能报 `unknown`，见 [ADR-0007](adr/0007-extension-observation.md)。
- 2 MiB 非流式响应已经越过旧 256 KiB 门槛进入 ContentStore；流式/SSE 和浏览器未交付的正文仍会留下缺口，不可宣称所有请求都有完整正文。
- 证据 JSONL 哈希链可检测局部篡改，但不具备对本机文件所有者的强不可抵赖性；显式清理尚无自动 TTL/配额执行器。见 [ADR-0002](adr/0002-content-evidence-and-retention.md)。
- T-005～T-009 共用实现提交 `94958b0`，只能批量回退；本轮验收须接受或修正此 SOP 例外。

1. 开发前：在本文件把工作切片映射到蓝图 M 阶段、列出验收与风险；涉及架构取舍时新建 ADR。
2. 开发后：记录实际实现位置、命令和通过结果；未跑验证不得标为“已完成”。
3. 若范围、数据模型、迁移或验收门槛偏离蓝图：先写 ADR，并同步本文件和蓝图中的对应条目。
4. 每次只推进一个可纵向验收的切片；待办按 P0/P1/P2 保持精简，不把细枝末节堆进本页。
