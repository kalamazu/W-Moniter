## 已知边界

- 当前多工作区通过**独立数据库文件**隔离；这不是蓝图最终的 scoped schema。迁移决策见 [ADR-0001](adr/0001-workspace-directory-isolation.md)。
- HTTP/MCP 先通过 `workspace.open` 显式切换活动工作区；尚未实现每个普通动作都携带 `TargetRef.workspaceId`。
- TaskService 目前是主进程内存账本，应用重启后任务记录不会恢复；持久任务、取消回执与审计事件需要跟随 scoped schema 落库。
- 浏览器插件、登录状态、Cookie/站点存储的跨工作区数据库级台账，以及检查点恢复尚未实现，不能宣称完整隔离保证。
- 正文采集仍沿用旧上限与 LRU 路径，不能宣称“全量采集”已完成。

## 记录规则

1. 开发前：在本文件把工作切片映射到蓝图 M 阶段、列出验收与风险；涉及架构取舍时新建 ADR。
2. 开发后：记录实际实现位置、命令和通过结果；未跑验证不得标为“已完成”。
3. 若范围、数据模型、迁移或验收门槛偏离蓝图：先写 ADR，并同步本文件和蓝图中的对应条目。
4. 每次只推进一个可纵向验收的切片；待办按 P0/P1/P2 保持精简，不把细枝末节堆进本页。
