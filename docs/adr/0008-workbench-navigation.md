# ADR-0008：工作台采用“活动栏 + 视图侧栏 + 可编排窗格”的三层导航

状态：接受（T-015，2026-09-24）

## 决定

工作台分成三层：顶部只承载应用身份、连接摘要、全局命令和操作系统窗口控制；左侧活动栏用于一级能力域切换；可折叠侧栏承载该能力域的具体视图；中间继续使用已持久化的自由多窗格布局。运行 target、登录/扩展等上下文不再以无边界标签堆满主区，而在按需打开的运行时抽屉中呈现。设置也采用抽屉，不假装成能够修改尚未实现的后端配置。

命令面板是跨视图的可发现入口，提供已有视图切换、布局和设置操作，并支持 `Ctrl+Shift+P`；请求检索仍留在请求视图的专用筛选栏，避免把全局命令与数据过滤混为一谈。键盘焦点遵循复合控件的预期：Tab 在区域间移动，活动栏与侧栏按钮可见焦点且可用键盘触发。

## 后果

用户能在窄窗口仍可靠地操作最小化、最大化、关闭；所有既有面板有明确入口，仍可自由分栏以满足复杂排查。信息密度从“常驻全部状态”转为“默认摘要、需要时展开”。

新增导航状态默认只在会话内保存；已有 `layout` 继续按工作区持久化。是否持久化侧栏折叠、主题、快捷键，等设置模型有明确产品契约后另立任务，避免把临时 UI 状态写成难以迁移的配置格式。
