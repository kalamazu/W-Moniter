## 验收范围

- 默认工作区兼容旧目录；新工作区创建为独立目录。
- 两个工作区可同时运行；打开第二个不会暂停第一个。
- 并发上限拒绝额外浏览器，不静默关闭已有工作区。
- 可只休眠一个工作区；焦点切回已运行工作区不重启浏览器。
- HTTP 控制面可列出工作区；既有控制面和 Profile 会话不回归。
